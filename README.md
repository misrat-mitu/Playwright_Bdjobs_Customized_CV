
### **Bdjobs Customized CV Upload Automation with Playwrignt**

This project contains a Playwright Python automation script for testing the Customized CV upload functionality of the Bdjobs website.
````markdown
## 📌 Project Overview

The automation script navigates through the Bdjobs website and automates the process of uploading a customized CV.

## 🛠️ Technologies Used

- Python
- Playwright
- Pytest
- VS Code

## ✅ Automated Flow

The automation covers the following steps:

1. Open the Bdjobs website
2. Log in to the Job Seeker account
3. Navigate to **MyBdjobs**
4. Open **Manage Profile**
5. Navigate to **Customized CV**
6. Click **Add Customized CV**
7. Upload a CV file
8. Verify the CV upload functionality
````

## ⚙️ Prerequisites

Make sure Python is installed on your system.

### Install Playwright

```bash
pip install playwright
```

### Install Playwright Browsers

```bash
playwright install
```

### ▶️ How to Run

Run the automation script using:

```bash
python first_test.py
```

## 🎯 Purpose

The purpose of this project is to practice web automation testing using Playwright with Python and automate the Customized CV upload workflow of Bdjobs.
